DOWNLOAD METHODS
================================================================================

Option 1: Wikimedia API Query (Recommended for automation)
  curl -s "https://commons.wikimedia.org/w/api.php?action=query&titles=File:FILENAME&prop=imageinfo&iiprop=url&format=json" | jq '.query.pages[].imageinfo[0].url'

Option 2: Direct URL Construction
  Extract wikimedia_title from manifest
  https://upload.wikimedia.org/wikipedia/commons/[encoded_path]/[filename]

Option 3: Batch Download Script
  Extract all urls from manifest and use wget with manifest-derived filenames
  See BATCH_3_IMAGE_GUIDE.md for detailed examples

Expected Volume: 36 images × 2-5MB average = 72-180 MB total
