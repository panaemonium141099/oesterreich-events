# Austrian Festival Blog Posts - Generated Content

## Project Summary

This directory contains automatically generated HTML blog posts about 50 authentic Austrian traditional festivals ("bräuchtümliche Feste"). The generator creates completely unique, SEO-optimized posts with German-language content, historical accuracy, and the exact approved template design.

## File Structure

Each HTML file is fully self-contained with:

```html
<!DOCTYPE html>
<html lang="de">
  <head>
    - Responsive viewport meta
    - SEO meta tags & JSON-LD structured data
    - OG tags for social sharing
    - Google Fonts & custom CSS
  </head>
  <body>
    - Progress bar (fixed top)
    - Hero section (full viewport)
    - TOC sidebar (appears after hero)
    - Article Part 1: Intro + Key Facts + Stats + Ad Slot 1
    - Full-bleed image section
    - Article Part 2: Traditions section
    - Interlude quote section
    - Article Part 3: Program + Ad Slot 2 + Gallery + Practical Info + Ad Slot 3
    - CTA section
    - JavaScript (animations, progress tracking, TOC)
  </body>
</html>
```

## Content Structure

### Each Festival Post Includes:

**Metadata:**
- SEO title (60 chars, includes year + location)
- Meta description (160 chars)
- 5-7 keywords
- JSON-LD BlogPosting schema
- Open Graph tags for social media

**Content Sections:**

1. **Intro Lead** (~150 words)
   - Atmospheric, poetic tone
   - Introduces the festival's significance
   - Mentions UNESCO/heritage status if applicable

2. **Key Facts** (6 items)
   - Termin/Datum
   - Ort/Location
   - Art des Brauchtums
   - Eintritt/Entry
   - Teilnehmer/Participants
   - Tradition seit/Since

3. **Stats** (3 badges)
   - Unique metrics (years, participants, duration)

4. **History Section** (~200 words + 5-entry timeline)
   - Real historical facts
   - 2 paragraphs of narrative
   - 5 timeline entries with dates

5. **Traditions Section** (~200 words)
   - Describes actual customs and practices
   - 2-3 paragraphs
   - Details about costumes, music, rituals

6. **Program** (5 timeline events)
   - Time (Uhrzeit)
   - Event name
   - Brief description

7. **Gallery** (3 images)
   - Each with descriptive caption
   - Masonry layout (2+1)

8. **Practical Info** (6 cards)
   - Anreise Bahn (Train)
   - Anreise Auto (Car)
   - Wetter (Weather)
   - Unterkunft (Accommodation)
   - Beste Position (Best viewing spot)
   - Tickets/Eintritt (Tickets)

9. **CTA** (Call-to-Action)
   - "Alle Brauchtumsfeste Österreichs" button

## Naming Convention

Files follow pattern: `NN-slug-name.html` where:
- `NN` = two-digit festival number (01-50)
- `slug-name` = URL-friendly festival name in lowercase with hyphens

Examples:
- `01-imster-schemenlaufen.html`
- `05-telfer-schleicherlaufen.html`
- `50-rankweiler-martinsritt.html`

## Generation & Extension

### To Generate All 50:

1. Expand `FESTIVALS` list in `generate_festival_blogs.py`
2. Add entries for festivals 04-50 with unique content
3. Run: `python3 generate_festival_blogs.py`
4. All 50 individual files + combined file auto-generated

### Data Requirements Per Festival:

Each festival entry requires ~25 fields of unique content:
- Festival name, slug, region, date, location
- Reading time estimate
- Poetic subtitle (unique per festival)
- ~150-word introduction
- 6 key facts (date, location, type, entry, participants, tradition since)
- 3 unique statistics
- History section title + ~200 word narrative + 5 timeline entries
- Fullbleed image caption
- Traditions section title + ~200 word description
- Atmospheric quote
- Program/Schedule (5 events with times)
- Gallery captions (3 items)
- Practical info (6 location-specific tips)
- SEO title, description, 5-7 keywords
