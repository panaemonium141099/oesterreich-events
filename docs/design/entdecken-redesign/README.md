# Entdecken-Redesign: drei Mockup-Varianten (2026-10-22)

Statische HTML-Mockups mit echten Events von lasstreffen.at/entdecken (Preise fürs Mockup ergänzt).
`index.html` öffnen und oben zwischen Varianten und Desktop/Handy wechseln.

| Variante | Vorbild | Idee |
|---|---|---|
| A `a-poster.html` | Dice.fm, Eventbrite | Hochkant-Poster-Grid, Schnellfilter-Chips + Kategorie-Leiste, Tage als Sticky-Header |
| B `b-regale.html` | Netflix, Airbnb | Top-Picks-Bühne, kuratierte Querscroll-Regale, Regionen als Bildkacheln |
| C `c-tagesplan.html` | Resident Advisor, Songkick | Große Datumszahl links, dichte Zeilen mit Uhrzeit/Venue/Preis/Ticket, Filterleiste |
