# fn-11-social-features-launch-ready-uxlogic-fix.1 Foundation: Toast System (Sonner) + Dark Theme Tokens

## Description
Install Sonner toast library and define dark theme tokens via Tailwind v4 `@theme`. This is the foundation all other tasks depend on.

**Size:** M
**Files:** `package.json`, `src/app/globals.css` (or main CSS), `src/app/layout.tsx`

## Approach

- `npm install sonner`
- Add `<Toaster />` component to root `layout.tsx` (must be in root layout so toasts persist across route changes in App Router)
- Configure Sonner theme to match dark mode (dark background, light text)
- Define `@theme` tokens in the main CSS file:
  - `--color-surface: #0a0a0c` (canonical page background)
  - `--color-surface-elevated: #141416` (cards, modals, overlays)
  - `--color-surface-inset: #050506` (inputs, code blocks)
- Verify `bg-surface` and `bg-surface-elevated` utility classes are generated by Tailwind v4
- Reference existing dark theme usage in `src/components/Layout/SocialNav.tsx` for glass-morphism style tokens

## Key context

- Tailwind v4 uses `@theme` directive in CSS (not `tailwind.config.js`) to define design tokens
- Sonner's `<Toaster />` accepts `theme="dark"` prop and `toastOptions` for custom styling
- Existing `NotificationToast.tsx` is realtime-only (Supabase INSERT events) — NOT a general toast. Do not modify it.
- Existing `AuthErrorToast.tsx` is landing-page-only. Do not modify it.
