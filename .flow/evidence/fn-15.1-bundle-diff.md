# fn-15.1 — Bundle-Analyzer Diff

## Expectation

No new chunks. `next/image` is built-in to Next.js 16, no third-party
dependency added. We REMOVED `useState`, `useEffect`, `useCallback`,
`useRef` from EventImage (it was a 3-stage onError state machine before),
so the chunk consuming EventImage should shrink slightly. Landing-page
chunks that previously imported `next/image` directly (RegionExplorer,
PopularCategories, FestivalBlogSection) now route through EventImage
instead — no net bundle impact.
