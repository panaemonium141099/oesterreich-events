## EventImage API (new)

```ts
type SharedProps = {
  src?: string | null;
  category?: string | null;
  fallbackCategory?: string | null;     // spec-alias for category
  title?: string | null;
  bundesland?: string | null;
  sizes: string;                        // required
  alt?: string;
  className?: string;
  wrapperClassName?: string;
  loading?: 'eager' | 'lazy';
  fetchPriority?: 'high' | 'auto' | 'low';
  preload?: boolean;                    // Next.js 16 replaces priority
  showGradientOverlay?: boolean;
  showSkeleton?: boolean;
  objectPosition?: string;
  objectFit?: 'cover' | 'contain' | 'fill' | 'none' | 'scale-down';
  placeholder?: 'blur' | 'empty';
};

// Discriminated union — fill mode is default. Fixed pixel size requires
// fill: false PLUS both width and height (compiler-enforced).
type EventImageProps =
  | (SharedProps & { fill?: true; width?: never; height?: never })
  | (SharedProps & { fill: false; width: number; height: number });
```

Helper exported alongside: `normalizeCategoryToSlug(name)` — transliterates
ä→ae, ö→oe, ü→ue, ß→ss, "&" → "-", normalizes whitespace and strips
non-slug characters. `'Märkte & Feste'` → `'maerkte-feste'`. Tested with
6 unit cases.
